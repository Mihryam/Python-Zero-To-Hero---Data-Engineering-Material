# CropGuide SQL Practice Database

This SQLite database is designed for beginner-to-intermediate SQL practice.

## Included tables

- `farmers` — 300 farmers
- `crops` — 12 crop types
- `farm_records` — 900 seasonal farm records
- `market_prices` — about 1,900 market price observations
- `weather_readings` — 1,800 weather readings
- `farmer_performance` — a ready-made SQL view joining farmers, farm records, and crops

## Good for practising

- SELECT
- choosing columns
- WHERE
- LIKE
- IN
- BETWEEN
- ORDER BY
- COUNT, SUM, AVG, MIN, MAX
- GROUP BY
- HAVING
- JOIN
- business questions involving multiple tables

## Suggested order

1. Start with the `farmers` table.
2. Practise SELECT and filtering.
3. Add ORDER BY.
4. Learn aggregate functions and GROUP BY.
5. Add HAVING.
6. Join farmers, farm_records, and crops.
7. Use market_prices and weather_readings for business questions.

The file `business_queries.sql` contains sample practice queries.
